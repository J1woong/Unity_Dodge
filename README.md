# Unity_Dodge

닷지 게임 수정 사항
-UI개선-
•메인 메뉴 구성
  새로운 메뉴 씬을 생성하고, 버튼 클릭을 통해 사용자와 상호작용할 수 있도록 설계.
  초기 로비 화면에는 다음 세 가지 주요 버튼이 표시.
  : Game Start, Characters, Exit
•Game Start 메뉴
  선택 가능한 난이도 버튼 추가: Easy, Normal, Hard
  각 난이도를 선택하면 해당 난이도에 맞는 씬으로 전환.
  뒤로가기 버튼을 통해 언제든지 초기 로비 화면으로 돌아갈 수 있도록 설정.
•Characters 메뉴
  플레이어 캐릭터의 색상을 선택할 수 있도록 총 4가지 색상을 추가.
  뒤로가기 버튼을 통해 언제든지 초기 로비 화면으로 돌아갈 수 있도록 설정.
•Exit 메뉴
  게임이 종료되도록 구현.
•사운드 미리듣기
  사운드 볼륨을 조절할 수 있는 사운드 바를 추가.
  Play와 Pause 버튼으로 사운드를 미리 들어보거나 일시정지 가능.

-인게임 개선-
•카메라 시점 변경
  탄환의 움직임을 더욱 명확히 인식하고 회피할 수 있도록 개선.
  기존 대각선 시점 → 탑다운(Top-down) 시점으로 변경.
•불릿 스포너 개선
  플레이어 경로에 방해되지 않도록, 벽에서 불릿 생성이 이루어지도록 조정.
•난이도 별 씬 구성
  Easy, Normal, Hard 각각에 맞는 별도의 씬 생성.
  •Easy : 불릿 스포너의 생성주기를 기존 0.5f ~ 3f의 랜덤 주기에서 3f로 고정 및 발판 회    전 제거
  •Normal : 불릿 스포너의 생성주기를 기존 0.5f ~ 3f의 랜덤 주기에서 1f로 고정 및 발판    회전 제거
  •Hard : 불릿 스포너의 생성주기를 기존 0.5f ~ 3f의 랜덤 주기에서 1f로 고정 및 발판 회    전 적용
•플레이어 기능 추가
  플레이어 Health 시스템 추가
  플레이어에게 총 3개의 목숨 부여.
  불릿에 피격 시 Health 1 감소 → 0이 되면 사망.
  현재 Health는 좌측 상단 UI 이미지로 표시.
•사운드 시스템
  각 난이도 씬에 Sigma_Boy 사운드 트랙을 추가하여 배경음악으로 설정.
•사망 시 기능
  기존의 R 키 재시작 기능 유지.
  ESC 키를 누르면 초기 로비 화면으로 이동할 수 있도록 기능 추가.
•아이템 추가
  불릿에 닿아 줄어든 Health를 회복 시킴.
  3초 안에 먹지 않을 경우 사라짐.
  최대 체력을 초과시켜 회복하지 않음.
